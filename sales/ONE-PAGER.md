# REPLATFORM — هندسة عكسية منظمة، بلا تنفيذ على مضيفك

**منصة ويندوز محلية لتحليل PE/APK وYARA والتفكيك وفحص الدفعات، مع وكلاء ذكاء
اصطناعي مقيدين وواجهة ويب محمية. لا ترفع عيّنات. لا تنفّذ عيّنات على المضيف
افتراضياً. كل تعديل قابل للاسترجاع.**

الإصدار 1.5.2 · Windows 10/11 · Python 3.11+ · النواة MIT · حالة Beta

---

## المشكلة

فريق صغير يحلّل عيّنة فيجمع: محرراً سداسياً، `strings`، YARA، Ghidra، أدوات APK،
وسكربتات متناثرة — على جهاز العمل نفسه. النتيجة: نتائج غير قابلة للتكرار، خطر
تشغيل غير مقصود، ولا سجل يثبت ما فُعل.

## ما يفعله REPLATFORM

| القدرة | القيمة العملية |
|---|---|
| تحليل PE | أقسام، إنتروبيا، استيرادات، ASLR/DEP/CFG، .NET، توقيع Authenticode |
| تحليل APK | الأذونات، المكونات المصدّرة، debuggable، cleartext، ABI، توقيع v1–v4 |
| YARA | 19 قاعدة محلية قابلة للتوسعة |
| التفكيك | Rizin وGhidra headless (pseudocode) عند توفرهما |
| فحص دفعات | مجلد كامل → HTML/JSON/CSV مع تحييد حقن الصيغ |
| مقارنة نسخ | `diff` مقاوم للإزاحة + تقرير |
| وكلاء | قواعدي بلا إنترنت، أو LLM عبر HTTPS فقط، بأدوات قراءة فقط |
| واجهة ويب | محلية افتراضياً، رمز دخول، allowlist مضيفين |
| سجل تدقيق | سلسلة تجزئة + تصدير موقّع (قدرة مؤسسية) |
| تقرير أسطول | تجميع مساحات العمل (قدرة مؤسسية) |

## الأمان أولاً — ما لا نفعله

- **لا تنفيذ افتراضي للعيّنات.** التشغيل الديناميكي فقط عبر Windows Sandbox
  وبإذن صريح `--run --yes`.
- **لا رفع عيّنات.** الموصلات ترسل استعلامات نصية فقط، ومعطّلة افتراضياً.
- **لا مفاتيح في الملفات.** من متغيرات البيئة فقط.
- **لا قياس عن بُعد، ولا اتصال بخادم ترخيص.**
- **لا حكم «آمن/خبيث».** المؤشرات تحتاج مراجعة بشرية.

## ما لا ندّعيه

- **Windows فقط** في 1.5.2؛ لا دعم Linux/macOS.
- **لا شهادات** SOC 2 / ISO 27001، ولا اختبار اختراق خارجي، ولا شهادة توقيع كود.
- **الأدوات الخارجية** (Ghidra/JDK/apktool/jadx/YARA/Rizin) غير مضمَّنة.
- **الترخيص offline** لا يمنع إرجاع ساعة النظام، ولا يفرض المقاعد تقنياً.
- **سجل التدقيق** يكتشف التعديل اليدوي ولا يمنعه.
- **الكود منشور تحت MIT**؛ الاشتراك يبيع التفعيل الرسمي والدعم والتحديثات
  والتغطية التعاقدية، لا احتكاراً تقنياً.
