> **داخلي/للعميل.** الأجوبة قابلة للتحقق من المستودع. لا تدّعِ شهادة أو اختباراً
> غير موجود. آخر تحديث: 2026-10-27.

## 1. نظرة عامة

**المنتج:** منصة ويندوز محلية للهندسة العكسية والتحليل الثابت (PE/APK/YARA/
تفكيك/فحص دفعات/مقارنة/وكلاء مقيدين/واجهة ويب محلية).
**النموذج:** سطح مكتب محلي. لا SaaS، ولا خادم مركزي، ولا multi-tenant.
**الحالة:** Beta. الوظائف الأساسية مستقرة، لكن واجهات CLI الداخلية قد تتغير.

## 2. تدفق البيانات

| المسار | ماذا يخرج؟ | متى؟ | الضابط |
|---|---|---|---|
| التحليل الثابت | لا شيء | دائماً | محلي بالكامل |
| الترخيص | لا شيء | عند التفعيل | تحقق Ed25519 محلي |
| التكاملات | استعلام نصي (هاش/اسم/مؤشر) | فقط إن فُعّلت | HTTPS + allowlist + مفاتيح بيئة |
| مزوّد LLM | سياق نصي من النتائج | فقط إن اخترت `llm` | HTTPS، بلا رفع ملفات، ميزانيات |
| الدعم | ما ترسله أنت | عند فتح بلاغ | تقليل البيانات مسؤوليتك |
| القياس | لا شيء | لا يوجد | غير مُنفَّذ |

**لا يوجد اتصال بخادم ترخيص، ولا telemetry، ولا تحديث تلقائي إجباري.**

## 3. التشفير

- **النقل:** TLS 1.2+ عبر `certifi`، رفض إعادة التوجيه، منفذ 443 فقط للموصلات.
- **التخزين:** لا تشفير على مستوى التطبيق. يعتمد على تشفير القرص (BitLocker)
  وصلاحيات NTFS. وثّق هذا للعميل بدل ادعاء تشفير غير موجود.
- **الأسرار:** متغيرات بيئة فقط؛ لا تُكتب في `config.json` ولا السجلات.
- **الترخيص:** توقيع Ed25519؛ المفتاح الخاص خارج المستودع.

## 4. المصادقة والصلاحيات

- **سطح المكتب:** صلاحيات مستخدم Windows. يُوصى بحساب غير مسؤول.
- **الواجهة الويب:** رمز Bearer/كوكي، افتراضياً `127.0.0.1`، allowlist مضيفين،
  رفض مسارات النظام.
- **RBAC:** غير موجود. لا أدوار متعددة داخل المنتج.
- **SSO:** غير مضمّن. تكامل عبر وكيل هوية خارجي يُسعَّر منفصلاً.
- **MFA:** على حسابات المالك (GitHub/البريد/الدفع)، لا داخل المنتج.

## 5. عزل التنفيذ

- **لا تنفيذ افتراضي للعيّنات على المضيف.**
- التشغيل الديناميكي فقط عبر Windows Sandbox، ويتطلب `--run --yes`.
- الشبكة داخل Sandbox معطّلة افتراضياً.
- **حد معروف:** يلتقط `stdout` فقط؛ لا ETW/Procmon، ولا مراقبة سلوكية كاملة.
- على أنظمة بلا Sandbox: استخدم VM منفصلة.

## 6. سلسلة التوريد

| الضابط | الحالة |
|---|---|
| اعتمادات تشغيل | 3 فقط (`pefile`, `asn1crypto`, `certifi`) |
| قفل بالبصمات | `requirements.lock` / `requirements-dev.lock` مع `--require-hashes` |
| SBOM | CycloneDX 1.5 لكل إصدار |
| بصمات | `SHA256SUMS` لكل أصل |
| توقيع | Sigstore keyless في CI (`cosign verify-blob`) |
| بناء حتمي | `--reproducible` يثبت تطابق البصمة |
| فحص اعتماديات | `pip-audit` في CI |
| تحديثات | Dependabot |
| فحص أسرار | `replatform.tools.secretscan` في CI |

## 7. دورة حياة التطوير

- فحص `ruff` بقواعد `F/E9/B/S` (S مكافئة لـ bandit).
- `mypy` صارم على 49 ملفاً.
- **615 اختبار `unittest`**، تغطية **94%** (حد CI 90%).
- fuzzing: 2,520 حالة ببذرة ثابتة.
- CI على Windows 2022/2025 × Python 3.11–3.14.
- **مراجعة الكود:** مشرف واحد؛ لا مراجعة مستقلة إلزامية. وثّق ذلك بصدق.
- **لا اختبار اختراق خارجي** ولا برنامج مكافآت.

## 8. إدارة الثغرات

- قناة خاصة: GitHub Security Advisory أو `@tuobaibrahim-ai`.
- أهداف: إقرار 7 أيام عمل، تقييم أولي 14 يوماً (ليست تعهداً تعاقدياً).
- لا Bug Bounty.
- الإفصاح المنسّق، وذكر الباحث إن رغب.

## 9. الاستجابة للحوادث

- يقودها المالك؛ لا فريق SOC ولا تغطية 24/7.
- إشعار العميل بالإخلال المؤثر على بياناته الشخصية خلال 72 ساعة (DPA).
- للثغرات: تقييم، إصلاح، إصدار تصحيحي، ملاحظات إصدار.
- لا التزام زمني للحل خارج SLA المدفوع.

## 10. سلامة الإصدار

```powershell
Get-FileHash -Algorithm SHA256 .\replatform-1.5.2-portable.zip
cosign verify-blob --bundle .\replatform-1.5.2-portable.zip.sigstore.json `
  --certificate-identity-regexp "https://github.com/tuobaibrahim-ai/replatform/.*" `
  --certificate-oidc-issuer https://token.actions.githubusercontent.com `
  .\replatform-1.5.2-portable.zip
```

- **لا شهادة توقيع كود** (Authenticode). البديل Sigstore keyless قابل للتحقق.
- لا مثبّت MSI؛ توزيع ZIP محمول + wheel/sdist.
- التحديثات لا تُثبَّت تلقائياً.

## 11. سجل التدقيق

- سلسلة تجزئة محلية (`audit.jsonl`) + تصدير ببصمة SHA-256.
- **يكتشف** التعديل اليدوي، **ولا يمنعه**.
- قفل بين العمليات منذ 1.5.1.
- ليس بديلاً عن SIEM مركزي.

## 15. الذكاء الاصطناعي

- الوضع الافتراضي قواعدي بلا إنترنت.
- LLM اختياري، متوافق مع OpenAI، HTTPS فقط.
- الأدوات قراءة فقط، مع حدود خطوات/وقت/سياق.
- لا تُرفع الملفات؛ يُرسل سياق نصي محدود.
- يمكن تعطيل المزوّد كلياً (`heuristic` أو `none`).

## 16. الترخيص

- Ed25519، تحقق محلي، بلا شبكة.
- لا DRM، لا فرض تقني للمقاعد.
- 14 يوماً سماح بعد الانتهاء.
- يعتمد على ساعة النظام؛ لا حماية ضد إرجاع الساعة.
- المفتاح الخاص محفوظ خارج المستودع؛ فقدانه يعني إعادة إصدار التراخيص.

## 17. حدود معروفة

- Windows فقط في 1.5.2.
- Beta؛ تغييرات CLI محتملة.
- الأدوات الخارجية غير مضمّنة.
- Sandbox يلتقط `stdout` فقط.
- لا مراقبة سلوكية كاملة (ETW/Procmon).
- لا شهادات، لا pentest، لا توقيع كود.
- الموصلات ذات المفاتيح التسعة لم تُجرَّب حياً لغياب مفاتيح المالك؛
  التطبيع مغطى بـ fixtures.
