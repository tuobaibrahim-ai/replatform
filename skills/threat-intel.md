# استخبارات التهديدات

## ترتيب المصادر
1. **مصادر أولية:** NVD/CVE للتفاصيل، CISA KEV للاستغلال المؤكد.
2. **مصادر مجتمعية:** OTX وVirusTotal وMalwareBazaar للسياق والسمعة.
3. **مصادر محلية:** سجلاتك، YARA، ونتائج التحليل الثابت.

## قواعد الثقة
- التجزئة تطابق تام؛ النطاق أو IP قد يتغير مالكه.
- نتيجة "لا شيء" ليست دليل براءة.
- افصل بين الحقيقة (CVE موجود) والتفسير (هجوم محتمل).
- اذكر تاريخ الاستعلام، لأن السمعة تتغير.
- لا ترسل ملفات أو محتوى عينات؛ أرسل مؤشراً بعد موافقة.

## ربط CVE بالاستغلال
- وجود CVE في KEV يعني استغلالاً فعلياً مؤكداً.
- CVSS وحده لا يكفي؛ اربطه بالتعرض الفعلي والأصول المتأثرة.
- تحقق من المنتج والإصدار بدقة قبل الحكم.

## الإخراج
مؤشر + نوعه + المصدر + التاريخ + درجة الثقة + الأثر المحتمل + خطوة التحقق.
