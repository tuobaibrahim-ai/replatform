# تقوية السحابة وقواعد البيانات

## الهوية والصلاحيات
- أقل صلاحية: مستخدم تطبيق منفصل لكل خدمة.
- لا تستخدم حساب المالك في التطبيق.
- فعّل MFA على لوحة التحكم.
- راجع مفاتيح API ودوّرها دورياً.

## الشبكة
- لا تعرض قاعدة البيانات للإنترنت إن أمكن.
- قيّد عناوين المصدر أو استخدم Private Link/شبكة خاصة.
- HTTPS فقط، وHSTS عند الإنتاج.
- لا تفتح منافذ الإدارة للعالم.

## قاعدة البيانات
- استخدم استعلامات مُعاملة، وامنع SQL الديناميكي.
- فعّل RLS في Supabase/Postgres عند تعدد المستخدمين.
- شفّر النسخ الاحتياطية، واختبر الاستعادة.
- راقب الحجم والاتصالات والاستعلامات البطيئة.
- لا تخزّن أسراراً غير مشفرة في الجداول.

## الخدمات المجانية
- اقرأ حدود الخادم والاتصالات والتخزين.
- احذر الإيقاف عند الخمول وفقدان البيانات.
- لا تعتمد على نسخة مجانية لبيانات إنتاج حساسة.
- راجع شروط الاستخدام وسياسة البيانات.

## المراقبة
- سجلات وصول دون بيانات حساسة.
- تنبيهات للفشل المتكرر أو الحجم غير الطبيعي.
- اختبار نسخ احتياطي دوري.
