# دليل البيع والتفعيل — SALES & FULFILLMENT RUNBOOK

دليل تشغيلي للمالك: من استفسار العميل إلى ترخيص مفعّل وتجديد.

## 1. المسار الكامل

```
استفسار → تأهيل → عرض مكتوب → فاتورة → سداد → إصدار ترخيص → تسليم → تفعيل → تجديد
```

## 2. التأهيل (Qualification)

اجمع قبل أي عرض:

- الاستخدام: داخلي / منتج / بحثي / تعليمي.
- عدد المقاعد والفرق.
- البيئة: Windows 10/11؟ شبكة معزولة؟ صلاحيات تثبيت؟
- هل يحتاج `audit` فقط أم `fleet` أيضاً؟
- متطلبات امتثال (سياسة داخلية، DPA، مراجعة أمنية).
- من يوقّع، وما مدة الشراء.

**ارفض** أي طلب يتضمن تحليل عيّنات خبيثة نيابة عن العميل أو تجاوز حمايات.

## 3. العرض

استخدم `docs/COMMERCIAL.md` كأساس، وخصّص:

- النطاق (القدرات + عدد المقاعد + المدة).
- السعر الإجمالي والعملة وطريقة السداد.
- تاريخ البداية والانتهاء.
- حدود المسؤولية وSLA المرجعي.
- شرط الاسترداد (14 يوماً).

لا تبدأ العمل قبل موافقة كتابية.

## 4. إصدار الترخيص

المفتاح الخاص **لا يُرفع للمستودع** ولا يُرسل بالبريد. المسار الافتراضي:

```
%USERPROFILE%\.replatform\license_private.key
```

إصدار ترخيص سنوي لعميل Professional بخمسة مقاعد:

```powershell
python -m replatform.tools.license_admin issue `
  --tier professional `
  --customer "ACME Corp" `
  --seats 5 `
  --days 365 `
  --out "C:\secure\ACME-2027.json"
```

لخطة Enterprise مع استحقاق إضافي:

```powershell
python -m replatform.tools.license_admin issue `
  --tier enterprise --customer "ACME Corp" --seats 25 --days 365 `
  --feature fleet_report --out "C:\secure\ACME-2027-ent.json"
```

تحقق قبل التسليم:

```powershell
python -m replatform.tools.license_admin verify "C:\secure\ACME-2027.json"
```

يجب أن يعيد `"valid": true` و`"features"` متوقعة.

## 5. التسليم

1. أرسل الملف عبر قناة مشفّرة أو بوابة العميل (لا مرفقات بريد عادية).
2. أرسل تعليمات التفعيل:
   ```
   python repl.py license activate license.json
   python repl.py license status
   python repl.py doctor
   ```
3. اطلب من العميل إرسال مخرجات `doctor --bundle` (بلا أسرار) للتأكيد.

## 6. التجديد

- تذكير قبل 30 يوماً (`days_left` في `license status`).
- أصدر ملفاً جديداً بنفس `license_id` وتاريخ انتهاء أحدث.
- لا تحذف الترخيص القديم؛ استبدله بعد تأكيد العميل.

## 7. الاسترداد والإلغاء

| الحالة | الإجراء |
|---|---|
| إلغاء قبل 14 يوماً ولم يُستخدم | استرداد كامل |
| إلغاء بعد التفعيل | لا استرداد؛ يبقى صالحاً حتى الانتهاء |
| إخلال بـ RESPONSIBLE_USE | إنهاء فوري؛ لا استرداد |
| خطأ في الإصدار (مقاعد/مدة) | إعادة إصدار فورية |

## 8. السجلات

احتفظ لمدة 7 سنوات بـ: العرض الموقّع، الفاتورة، إثبات السداد، نسخة من
الترخيص الصادر (بدون المفتاح الخاص)، ومراسلات التسليم.

## 9. الضرائب والفوترة

الفاتورة يجب أن تحمل: الاسم القانوني، الرقم الضريبي إن وُجد، وصف الخدمة،
المدة، والمبلغ والعملة. استشر محاسبك؛ هذا الدليل ليس استشارة ضريبية.

## 10. مؤشرات نجاح ربع سنوية

- نسبة التجديد (هدف ≥ 85%).
- زمن الإصدار والتسليم (هدف < يوم عمل).
- بلاغات P1 لكل عميل.
- عدد العملاء الذين يستخدمون `audit`/`fleet` فعلياً.
