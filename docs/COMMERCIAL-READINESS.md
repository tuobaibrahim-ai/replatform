## 1. الحكم في سطر واحد

يمكن بيع **Professional/Enterprise** لفرق الأمن الصغيرة والمتوسطة، ومختبرات
تحليل البرمجيات، والجامعات، والبيئات المعزولة — **بعد** استكمال بيانات
الفوترة والسداد والبريد التعاقدي والمراجعة القانونية. لا يمكن البيع للقطاع
الحكومي/المنظّم الذي يطلب SOC 2 أو ISO 27001 أو اختبار اختراق خارجي أو
مثبّتاً موقّعاً بشهادة كود.

## 5. الشرائح التي يمكن البيع لها الآن

| الشريحة | لماذا تناسب | ما يجب قوله |
|---|---|---|
| فريق أمن صغير (5–25) | يحتاج تنظيماً وسجلاً، لا شهادات | ابدأ بـProfessional + تقييم |
| استشارات IR/تحقيق | يريد تكرار النتائج وتقارير | `scan`/`diff`/`audit` |
| مختبر بحث برمجيات خبيثة | يريد تحليلاً محلياً بلا رفع | لا تنفيذ على المضيف |
| جامعة/مختبر أكاديمي | ميزانية محدودة | خصم 50% |
| بيئة معزولة/air-gapped | لا خادم ترخيص | ترخيص offline |
| فريق هندسة عكسية داخلي | يريد واجهة موحدة | تكاملات اختيارية |

## 6. الشرائح التي لا نبيع لها

- جهة تطلب **SOC 2 / ISO 27001 / FedRAMP** أو تقرير اختراق خارجي.
- جهة تطلب **مثبّتاً MSI موقّعاً** بشهادة كود.
- بيئة **Linux/macOS** فقط.
- جهة تطلب **دعماً 24/7** أو محلل عيّنات نيابة عنها.
- أي استخدام هجومي أو تحليل برمجيات بلا تصريح.
- جهة تطلب **ضمان «صفر إنذارات كاذبة»** أو «كشف كل تهديد».

## 7. قائمة Go / No-Go لأول بيع

- [ ] الكيان القانوني والعنوان والرقم الضريبي جاهزة.
- [ ] وسيلة استلام السداد محددة (دون تخزين بطاقات).
- [ ] بريد/قناة دعم تعاقدية تعمل.
- [ ] EULA/SLA/DPA/الاسترداد روجعت قانونياً.
- [ ] السعر مطابق لـ`sales/PRICING.md` أو موثّق كاستثناء.
- [ ] العميل ليس في الشريحة المحظورة (لا استخدام هجومي/عيّنات).
- [ ] العرض والطلب موقّعان.
- [ ] الترخيص صادر ومتحقق (`valid: true`).
- [ ] الحزمة متحققة البصمة والتوقيع.
- [ ] قائمة التسليم (`sales/DELIVERY-CHECKLIST.md`) مكتملة.
- [ ] العميل يعرف حدود Beta وWindows وغياب الشهادات.
- [ ] سياسة الاسترداد مُرسلة.
