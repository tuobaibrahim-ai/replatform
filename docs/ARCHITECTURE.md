# البنية المعمارية — REPLATFORM

## 1. المبادئ الحاكمة

البنية مبنية على خمس ثوابت لا تُخترق في أي تغيير:

1. **لا تنفيذ للعيّنات على المضيف.** التحليل ثابت افتراضياً. التشغيل الديناميكي
   حصراً عبر Windows Sandbox وبإذن صريح (`--run --yes`).
2. **فصل القراءة عن الكتابة.** كل عملية تعديل (`patch`) تمر بمعاينة، ثم نسخة
   احتياطية، ثم كتابة، ثم تحقق بنيوي، ثم استرجاع تلقائي عند الفشل.
3. **الخطر صريح.** الشبكة، والتنفيذ، وتغيير الطول، ومجلدات النظام: كلها خلف
   أعلام صريحة، لا افتراضات.
4. **موارد محدودة.** كل محلل له سقف حجم/وقت/مدخلات معلن في `config.json`،
   ويُعيد `skipped` بدل استنزاف الذاكرة.
5. **محلي أولاً.** لا قياسات، ولا سحابة، ولا رفع عيّنات. المفاتيح من البيئة.

## 2. الطبقات

```
نقاط الدخول
  repl.py · python -m replatform · replatform/cli.py
  replatform/web/server.py (واجهة محلية) · scripts/*.ps1 (أدوات مساعدة)
        │
التنسيق (Orchestration)
  analyzers/__init__.py (تشغيل + إضافات) · agents/loop.py (حلقة الوكيل)
  tools/batch.py (دفعات) · tools/bindiff.py (مقارنة) · reports/ (تقارير)
        │
المحركات (Engines)
  analyzers/{pe,apk,strings,yara,disasm,ghidra}_analyzer.py
  tools/{patcher,apk_tools,sandbox,ghidra_tools,yara_engine,benchmark,selftest}.py
  integrations/{http,connectors,catalog}.py
        │
النواة (Core)
  core/{config,state,util,workspace,registry,export}.py
```

**قاعدة الاتجاه:** الطبقة الأعلى تعرف الأدنى، ولا العكس. `core/` لا تستورد
`analyzers/` ولا `cli.py`. هذا ما يجعل الوحدات قابلة للاختبار بلا شبكة أو واجهة.

## 3. تدفق التحليل

```
مسار المستخدم
   ↓ Target.from_path()        # وجود، ملف عادي، الحجم، SHA-256، النوع
   ↓ load_analyzers()          # 6 محللات مدمجة + إضافات plugins/
   ↓ can_handle(target)        # النوع + التفعيل + حدود الحجم + توفر الأداة
   ↓ run(target, ws)           # نتيجة موحّدة: score, verdict, findings, summary
   ↓ Workspace.save_artifact() # حفظ JSON + حدث في السجل
   ↓ reports.render()          # HTML مهرَّب
   ↓ export_pdf()              # اختياري: متصفح مثبّت (Edge/Chrome)
```

كل محلل يُعيد قاموساً بالعقد نفسه:

| المفتاح | المعنى |
|---|---|
| `score` | 0–10، شفاف وقابل للتفسير |
| `verdict` | `info` / `warn` / `critical` |
| `findings` | قائمة نصوص عربية قصيرة |
| `summary` | حقول بنيوية للعرض والوكيل |
| `error` / `skipped` | فشل أو تجاوز حد، بلا إسقاط العملية |

**الفشل معزول:** استثناء محلل واحد يُسجَّل في `ws` ويظهر في `errors`، ولا يمنع
بقية المحللات. هذا مقصود: عيّنة مشوّهة قد تُسقط محللاً واحداً فقط.

## 4. دورة حياة APK

```
validate_apk()  →  decode_apk()  →  [تعديل Smali/الموارد]  →  build  →  sign
   حجم/نسبة/مدخلات     مجلد معزول       مسؤولية المستخدم        apktool   مجلد مؤقت
                                                                          ↓
                                                              تحقق ZIP + v1/v2/v3/v3.1/v4
```

- `validate_apk` يرفض zip bomb (نسبة ضغط)، والمدخلات الكثيرة، والملفات الضخمة،
  والبيان الأكبر من الحد.
- `sign` لا يثق بكود الخروج وحده؛ يفتح الناتج ويتحقق من مخططات التوقيع.
- `decode --force` لا يحذف مجلداً موجوداً بصمت؛ يتطلب علماً صريحاً ويحمي
  التعديلات.

## 5. حلقة الوكيل

```
system prompt + skills + سياق المحللات
        ↓
provider.chat(messages, tools)   # HTTPS فقط، بلا redirect، سقف استجابة
        ↓
tool_calls → tools.execute()     # قراءة فقط، مسارات مقيدة، ميزانية نداءات
        ↓
tool result (مقتطع) → الرسائل → التكرار
        ↓
max_steps / max_seconds / max_tool_calls / compact_messages
```

الضوابط:

- `restrict_paths=true`: الأدوات ترفض أي مسار خارج الهدف/الجذور المسموحة.
- `max_tool_result_chars`: يمنع تضخّم السياق من ملف ضخم.
- `compact_messages`: يضغط الرسائل القديمة مع إبقاء مجموعات الأدوات متسقة
  (لا يُقطع `tool_call` عن نتيجته).
- المزوّد المحلي (`127.0.0.1`) مسموح بـ HTTP؛ البعيد HTTPS فقط.

## 6. الواجهة الويب

`web/server.py` خادم HTTP محلي بلا إطار عمل خارجي:

- افتراضياً `127.0.0.1`؛ الاستماع الخارجي يتطلب قراراً صريحاً.
- مصادقة: رمز في المسار/Bearer/كوكي، ومقارنة ثابتة الزمن.
- رفض `Host` غير موجود في `--allowed-host`.
- `resolve_analyze_target`: يرفض مسارات النظام، والروابط الرمزية، وما خارج
  الجذور المسموحة.
- قفل تحليل واحد لمنع استنزاف الموارد.
- كل محتوى العيّنة يُهرَّب قبل العرض (`esc`).

## 8. نقاط التوسعة

| النقطة | الآلية | العقد |
|---|---|---|
| محلل جديد | `plugins/*.py` | يرث `Analyzer`، يعرّف `name` و`can_handle` و`run` |
| قاعدة YARA | `rules/*.yar` | تُحمَّل تلقائياً؛ فشل الترجمة يُبلَّغ |
| مهارة وكيل | `skills/*.md` | تُدمج في رسالة النظام عند الطلب |
| موصل قراءة فقط | `integrations/connectors.py` | HTTPS + allowlist + استعلام نصي فقط |
| تقرير | `reports/` | HTML مهرَّب، ثم PDF اختياري |

## 9. قرارات معمارية مقصودة

- **بلا إطار ويب:** أقل سطح هجوم وأقل اعتمادات.
- **بلا قاعدة بيانات:** JSON + JSONL يكفي لتحليل أحادي المستخدم، ويسهل النسخ.
- **`cli.py` كبير:** أُجّل تفكيكه عمداً حتى تُثبَّت اختبارات انحدار لسطح الأوامر
  (`tests/test_cli.py`). التفكيك بلا شبكة أمان خطر.
- **الأدوات الخارجية غير مضمَّنة:** تراخيص Copyleft وحجم كبير؛ تُستدعى كعمليات.
- **`score` بسيط وقابل للتفسير:** المراجعة البشرية هي الحكم النهائي، لا النموذج.
